# KineticSculpture_PM3D
The goal of this project is to create a looping, mechanical, marble run track.

Originally the idea was to create a set of concentric rings angled apart such that the marble falls from one ring to the other, like in the preview below, but due to the mechanism required to spin the marbles along the tracks they couldnt fit together and stay concentric.
